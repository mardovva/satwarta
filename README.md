Satwarta (Satwa Warta)
Platform pelaporan masyarakat yang menemukan satwa liar terdampak karhutla yang memasuki permukiman akibat kerusakan habitat. Masyarakat dapat mengirim laporan lokasi dan kondisi satwa, sementara instansi terkait memverifikasi dan melakukan penyelamatan. Proses penanganan dapat dipantau masyarakat melalui fitur tracking.

Tech Stack:
Next.js	
React
TypeScript	
Tailwind CSS	
shadcn/ui	
Supabase	
PostgreSQL	
PostGIS	
MapLibre GL JS	
Recharts

Cara run (sementara):
Clone -> npm install -> npm run dev -> buka di local host
