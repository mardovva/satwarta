# 🐾 Satwarta

**Satwarta** adalah platform digital terintegrasi untuk membantu penanganan satwa liar terdampak kebakaran hutan dan lahan (karhutla). Menghubungkan masyarakat dengan lembaga penyelamat melalui pelaporan, pemantauan, dan koordinasi penyelamatan berbantuan AI.

**Website:** https://satwarta.vercel.app

## Fitur Utama

- **Interactive Map** — Memantau persebaran hotspot dan laporan satwa.
- **Wildlife Reporting** — Melaporkan satwa terdampak melalui formulir berbantuan AI.
- **AI Chat** — Pusat informasi dan panduan awal penanganan satwa.
- **Rescue Tracking** — Memantau perkembangan proses penyelamatan.
- **Agency Dashboard** — Mengelola, memverifikasi, dan memperbarui status laporan.
- **Donation** — Mendukung upaya penyelamatan satwa.
- **Rescue Organizations** — Menemukan informasi lembaga penyelamat.

## Tech Stack

| Lapisan | Teknologi |
|---|---|
| Frontend | Next.js 15, React 19, TypeScript |
| Styling | Tailwind CSS, shadcn/ui |
| Backend | Next.js Route Handlers |
| Database | Supabase, PostgreSQL |
| Geospatial | PostGIS, MapLibre GL JS |
| AI | Google Gemini API |
| External Services | NASA FIRMS, OpenStreetMap, Esri, Nominatim, Cloudflare Turnstile |
| Hosting | Vercel |

## Alur Sistem

1. Masyarakat memantau peta dan mengirimkan laporan satwa terdampak.
2. AI membantu proses pelaporan dan memberikan panduan awal.
3. Lembaga penyelamat menerima, memverifikasi, dan menangani laporan.
4. Petugas memperbarui status penyelamatan.
5. Masyarakat memantau perkembangan melalui fitur Tracking.
