# Gambar lingkaran posko di peta

Letakkan gambar gedung atau logo di folder ini dengan nama `<id>.png` (id ada di `src/data/institutions.ts`).
Bila file tidak ada, lingkaran menampilkan ikon gedung, jadi tidak ada yang rusak.

Saran: gambar persegi (mis. 256x256 px), PNG/JPG kecil (di bawah 100 KB). Pastikan Anda berhak memakai gambar itu
(logo dan foto gedung milik lembaga masing-masing): pakai logo dari situs resminya atau minta izin, dan cantumkan sumbernya.
Untuk memakai nama atau ekstensi lain, isi properti `image` pada lembaga di `src/data/institutions.ts`.

Nama file yang dikenali:
bksda-kalbar.png, bksda-kalteng.png, bksda-kaltim.png, ditjen-ksdae.png, bksda-jakarta.png, pps-tegal-alur.png,
alobi-babel.png, yiari-ketapang.png, yiari-bogor.png, bosf.png, yel-socp.png
